Ошибка на скриншоте вызвана устаревшим кодом в библиотеке Python (начиная с версии 3.10). Строка ssl.SSLContext() без аргументов вызывает предупреждение, а ssl.PROTOCOL_TLS — устарел.

Вот исправленный и полностью переписанный код. Я заменил устаревшие вызовы SSL на актуальные (ssl.PROTOCOL_TLS_CLIENT) и почистил код для корректной работы.

Что было исправлено:

1. SSL Context: Вместо ssl.SSLContext() (который вызывал DeprecationWarning) теперь используется функция create_ssl_context(), которая создает контекст через ssl.SSLContext(ssl.PROTOCOL_TLS_CLIENT). Это современный стандарт для клиентских соединений.
2. Отключение проверки сертификата: Добавлены строки context.check_hostname = False и context.verify_mode = ssl.CERT_NONE, чтобы избежать ошибок при подключении к сайтам с самоподписанными сертификатами или через прокси.
3. Чистка кода: Убраны лишние комментарии и "мертвый код", который не использовался.
4. Кодировка: Убедился, что вывод в консоль не ломается на спецсимволах.
